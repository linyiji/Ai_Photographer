# Profile: QA_CERTIFICATION V1.0

Modes: `VERIFY_ONLY`, `VERIFY_AND_BOUNDED_FIX`, `PO_REMEDIATION`.

Certify an existing implementation against explicit acceptance. Distinguish fixture, implementation, build, runtime, Preview, real-device, photography-quality, reality-preservation, and Product Owner visual results. A fixture cannot substitute for a real runtime unless explicitly named as Authority.

Bounded fixes must share the root cause, remain reversible/auditable/in scope, and preserve frozen invariants. Record negative cases, failure closure, known limitations, and deferred debt.
