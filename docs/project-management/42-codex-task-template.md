## Codex Progress Rule

Codex 每次正式任务结束必须：

1. 生成 Task Report；
2. 更新 `PROJECT_STATUS.md`；
3. 更新 `PROJECT_STATUS.json`；
4. 明确 PASS / FAIL / SOURCE_REQUIRED；
5. 列出 Known Issues；
6. 列出 Deferred Items；
7. 明确下一 Task；
8. 确认 Git status。
