# Scene Spatial Parallel Track Governance v0.1

Scene Spatial is an independent experimental owner of **WHERE / WHICH DIRECTION / WHICH AREA**. Live owns real-time alignment to a selected target; Main owns shared Session, Workflow, and product integration.

The spike is self-contained under `spikes/scene-spatial-photography`. Main and Live are read-only references. Selective adaptations become Scene-Spatial-owned source; runtime imports, filesystem access, package links, or server dependencies crossing worktrees are forbidden. Future integration is selective migration through the integration manifest, never a raw spike merge.
